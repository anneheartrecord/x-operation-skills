# X 发帖前「不发原则」自检门（发不发 Check）

在把一条推文交给 `x-post` 发布之前，先过这道门。目的不是拦一切，而是拦住**发了也白发、甚至稀释账号定位**的内容。宁可少发一条，不发一条没有判断、跟主线无关的流水。同时负责将检查结论（发/打回改/不发及理由）回填为文档属性。

**清单以账号运营手册为源**：唯一真相是 `~/Documents/knowledge-base/30-outputs/X 运营/账号运营手册.md` 二节的「发帖前五问」+「不发清单」。看板 `charles-media.html` 的 `SELF_CHECK` 已由 `media-dashboard-gen.py` **从手册自动派生**（重跑看板即同步）。改动只改手册，再重跑看板；别在看板或本文件里各维护一份。本 skill 与手册冲突时以手册为准。

## 输入

一条推文草稿（文件路径或直接粘贴的正文）。默认从 `~/Documents/knowledge-base/30-outputs/tweets/` 里的草稿取。

## 两道闸（顺序执行，任一判「不发」即停）

### 闸一：不发清单（黑名单，命中即打回或不发）

逐条核对草稿是否属于下面任一类。命中就不能直接发：

| # | 不发项 | 判定要点 | 处置 |
|---|---|---|---|
| 1 | 抽象大道理与空洞金句 | 只有感悟、口号、金句，无账本、无场景、无底层机制，虚空讲道理 | 打回：补真实账本/场景/因果链，否则不发 |
| 2 | 广播式自说自话 / 纯甩链接 | 单向发通知、甩 Github/项目链接，无「Why should I care」读者阅读理由 | 打回：补读者视角的前置价值与阅读理由 |
| 3 | 无钩子平铺直叙进入长段 | 第一行是概念推导或平铺直叙，无悬念、反差或直接利益点（0.5秒滑走） | 打回：改写第一句为真实动作或鲜明反常识 |
| 4 | 模型新闻评论（无一手实测） | 只是转述/点评某模型发布、跑分、更新，自己没上手实测（**但带自己判断/取舍的时效观察允许发**） | 打回：补一手实测数据/截图再发，否则不发 |
| 5 | 纯工具搬运 | 只是「发现个好工具，链接给你」，没有自己的用法/判断 | 打回：加自己的使用场景 + 判断 |
| 6 | 配图流水账 | 晒图/晒生活/晒结果，无观点无信息增量 | 不发 |
| 7 | MBTI / 星座 | 命理、人格标签类娱乐内容 | 不发（硬拒） |
| 8 | 纯转发 | 只是转发他人内容，无自己的增量观点 | 不发 |
| 9 | 没有判断的资讯 | 只报「发生了什么」，不给「我怎么看」 | 打回：补判断 |
| 10 | 纯吐槽 | 只有情绪锐评，没落到理由/边界/动作 | 打回：锐评转判断（给理由 / 给边界 / 给动作） |
| 11 | 只利己不利他 | 纯自嗨/炫耀/纯恰饭无干货，读者拿不走任何具体判断/方法/避坑；恰饭也必须给读者干货 | 打回：补一个读者能拿走的具体点，补不上则不发 |
| 12 | 闲聊 / 体验卡短推 | 无信息量的日常闲聊、体验卡 | 不发 |
| 13 | 裸自转推 | retweet 自己的旧帖（吃曝光零转化，一律改走 quote 规则） | 不发（改走 quote） |

### 🌟 转写推文专项前置硬核准入（2026-10-19 用户拍板确立）

凡用户提供了外部来源（视频/播客/访谈/文章链接或指定作者）的**转写推文**，必须无条件满足以下三项工业级硬指标，任一违规直接打回改：

1. **出处显式注明与同行审视口风**：
   - 标题必须采用 `# 读 @原作者 的...` 或 `# 转录 @原作者 的...`；
   - 开篇第一行必须以「今天看了 @原作者 聊...」或等价同行观察切入；
   - 通篇保持客观转述、提炼、对话与同行审视的姿态，**严禁将原作者的亲身经历、私有数据或独创观点包装抹平成个人原创**。
2. **题图截取规范（原视频 16:9 纯净画面）**：
   - 必须提取原视频 16:9 纯净画面（原视频封面或 16:9 播放画面）；
   - **严禁截取带有浏览器外框、顶部搜索栏、侧边栏推荐列表、评论区以及插播广告等网页 UI 杂质的整屏截图**。
3. **拒绝过度浓缩（保留全量硬核精华）**：
   - 严禁为了追求字数短小而把精华压缩成空洞概念；
   - 必须完整展开原作者的核心案例、完整建议项（例如原作者讲了 5 条建议就必须出齐 5 条，严禁擅自砍半）、数学量化推导（具体年限、金额、复利对比）与底层因果链。

### 闸二：发帖前五问 · 一票否决（五个都不占 → 别发）

过了闸一，再问这五个问题。**只要一个都不占，就别发**（反过来：至少命中一个才有资格发，命中越多越该发）：

1. **开头是肉身排雷/真实动作/鲜明反常识吗？**（第一句开场即事实，付出时间/金钱/试错成本或打破认知，拒绝抽象大道理与平铺直叙）
2. **交付极其确定的可拿走物了吗？**（命名测试：能用一个名词说出读者带走的东西——清单/步骤/实测/避坑路径/对比表，答不出不发）
3. **拆出底层机制或第一性原理了吗？**（讲透为什么大家都错、为什么会这样，严密因果链，绝非浮于表面感受）
4. **服务三条主线之一吗？**（AI 落地 / 技术人的钱 / 大厂之外的路）
5. **作者姿态是带着真实纠结的同行探索者吗？**（平视探索与真实交付，绝不居高临下布道，绝不广播式自说自话）

## 核心自检对照表（实测复盘沉淀）

| 维度 | 🚀 爆款特征（3万~20万曝光，200~1,000+收藏） | 🥀 扑街特征（<300曝光，0~1互动） |
|---|---|---|
| 开头第一句 | 真实动作 / 肉身踩坑 / 鲜明反常识（「昨天忙了一天…」） | 抽象大道理 / 口号 / 纯链接 / 平铺直叙（「流量真的很重要…」） |
| 内容交付物 | 清单 / 避坑战报 / 操作路径 / 原理对比（读者单帖能带走工具） | 纯感悟 / 个人状态广播（读者接不住、用不上） |
| 逻辑深度 | 拆出底层机制（为什么大家都错、为什么会这样） | 停留在表面感受（「我觉得挺有意思」） |
| 作者姿态 | 带着具体问题与真实纠结的同行探索者 | 居高临下的布道者，或自言自语的记录者 |
| 转写还原度 | 显式标注出处、16:9 纯净题图、完整保留案例与数据推导 | 假装原创、截取带广告的网页杂质图、过度浓缩丢掉细节 |

## 裁决输出（固定格式）

跑完两道闸，输出：

```
裁决: 发 / 打回改 / 不发

闸一·不发清单: 通过 / 命中第 N 条「XX」/ 命中转写准入「XX」
闸二·五问: 命中 [1/2/3/4/5 哪几条], 共 N 条
  1 开头肉身排雷/真实动作/反常识: 命中 / 不占
  2 交付确定可拿走物: 命中（带走物名称: XX）/ 不占
  3 拆出底层机制: 命中 / 不占
  4 主线定位: 命中（哪条主线）/ 不占
  5 同行探索者姿态: 命中 / 不占

理由: 一句话说清为什么是这个档
改法（仅打回改时给）: 具体缺什么、怎么补
```

### 写入文档属性（Frontmatter 自动注入）

当针对具体草稿文档（如 `30-outputs/tweets/*.md`）执行 check、或在推文起草流水线中执行本门检查时，**必须将裁决结论与理由作为 YAML frontmatter 属性写进文档头部**，方便长期追溯与看板识别：

```yaml
发帖结论: 发        # 选项：发 | 打回改 | 不发
结论理由: 开头以真实动作开场，交付了明确的4项实操清单与避坑路径，因果链拆解到底层机制，符合同行探索者姿态。
```
若裁决为「打回改」或「不发」：
```yaml
发帖结论: 打回改    # 或 不发
结论理由: 转写推文过度浓缩，漏掉了原作者的完整建议与推导数据；题图包含网页侧边栏杂质。
```

裁决规则：
- 闸一命中「不发」类 → **不发**。
- 闸一命中「打回改」类或转写准入违规 → **打回改**（先不发）。
- 闸一通过，闸二五问全不占 → **不发**（跟这个账号无关）。
- 闸一通过，闸二至少命中一问 → **发**。
- 商单/恰饭帖例外：不套涨粉向的五问、不判 P 级（单独走 `商务合作SOP与记录.md`），但闸一「只利己不利他」仍适用——恰饭也必须给读者干货，纯广告打回。

## 边界

- 本门只判「该不该发」，不判「文案好不好」。文风打磨走写作系统，开头优化走 `dbs-hook`，标题走 `xhs-title`，去 AI 味走 `de-ai-flavor`。
- 裁决「发」≠ 自动发布。发布永远是用户手动动作，或用户明确说发之后才走 `x-post`（先 dry-run 预览费用再确认）。
- 本门不改草稿正文，但**负责将裁决结论（发帖结论 / 结论理由）回填为文档 frontmatter 属性**。

## 与工具包其它 skill 的衔接

`x-hotspot-radar`（出稿）→ **`x-post-gate`（该不该发）** → `x-post`（发布）。
复盘侧：发过的帖用 `x-content-review` 出周报/月报，A 档扩系列、C 档停选题，反过来影响以后什么该发。
